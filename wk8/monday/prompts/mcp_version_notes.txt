Versioning:
- MINOR: add a tool while preserving all existing input/output contracts.
- MAJOR: rename an existing response field, change required inputs, or remove tools.
- PATCH: compatible fixes that do not change the contract.
- The planned required-input rename from item to item_code is draft only for
  2.0.0, with a proposed dual-argument shim in 1.2.x and a minimum 30-day
  deprecation window; neither change is implemented and the live pin is 1.1.0.
- version://current is the application version pin; no unsupported version=
  argument is passed to FastMCP. Do not confuse SDK metadata with this lab pin.
